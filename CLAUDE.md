## Design System
Always read `DESIGN.md` before making any visual or UI decisions.
All font choices, colors, spacing, and aesthetic direction ("Amber Terminal") are defined there.
Do not deviate without explicit user approval. In QA/design review, flag any code that
doesn't match DESIGN.md (e.g. violet/glassmorphism leftovers, bubbly radii, cold blue-black).
